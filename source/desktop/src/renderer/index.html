一键连接

用 Magpie 代理？按这样手动添加：
  1. 打开 Magpie → 资源库 → MCP 服务器 → 添加
  2. 名称填 mem0，运行方式选「命令」
  3. 命令填：npx -y mcp-remote
  4. 勾选要用的 Agent（如 Claude Desktop、WorkBuddy），保存
  5. 重启对应客户端
需要电脑已安装 Node.js。密钥变更后，这里的地址也要同步更新。

写入对方的 MCP 配置（原文件自动备份），重启该客户端后生效。
